Publish donors and spending

Creates public-data.json with verified donors and all spending. It never includes mobile numbers or UTR. A name shows only if the donor ticked the box, otherwise “Anonymous”.

  1. Open your GitHub repository.
  2. Add file → Create new file. Name it public-data.json.
  3. Paste the copied text and press Commit changes. The website updates in 1 to 2 minutes.
  4. Next time: open the file, press the pencil icon, replace the text, commit.
